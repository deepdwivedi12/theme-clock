# 📖 About

Theme Clock is a responsive web application that displays:

- 🕒 Analog Clock
- ⏰ Digital Clock
- 📅 Current Date
- 🌙 Dark Theme
- ☀️ Light Theme

The clock updates automatically in real time and provides a smooth user experience on both desktop and mobile devices.
